Problem statement & dataset

Predict which loans will default — before they're funded

The problem

On a peer-to-peer platform an investor sees only a loan application and must decide before any repayment. A default loses money. We predict paid vs. default (classification) and loan return (regression), using only features known at issue time (no leakage).

The dataset

LendingClub accepted loans (Kaggle), 2012–2015 final-status loans. Label: Fully Paid =1, Default =0.

Existing approaches & our add-on

What the paper did, and what we added

Existing (reproduced)

  • Logistic Regression — linear scorecard baseline
  • Neural Network — flexible non-linear model
  • Random Forest — many voting decision trees

Plus 6 regressors for return & a loan-selection strategy.

Our add-on (extension)

  • Gradient Boosting — trees built in a chain, each fixing the last one's errors
  • The one tabular family the paper skipped
  • With balanced class weights to catch the rare defaults
Why Gradient Boosting: fills the missing model family, handles the 81/19 imbalance, fast, and built into scikit-learn (no extra dependency) — over SVM/kNN (too slow at this scale) and XGBoost (extra install).

Our additional model

Gradient Boosting with balanced class weights

  • Builds decision trees in sequence, each correcting the previous trees' mistakes
  • class_weight="balanced" — makes rare defaults count ~4× so the model stops ignoring them
  • HistGradientBoostingClassifier, sklearn defaults otherwise
  • Trained on a 200k-row sample (8 GB RAM limit), evaluated on the full test set — same rows & metrics as Part 1, so comparison is fair
Gradient Boosting ROC — best AUC of all four (0.73)
Results from the additional model

It actually catches the defaults

  • Catches 67% of defaults — like Logistic Regression, and 10× the Random Forest's 6%
  • Highest AUC (0.731) and best Default-F1 (0.43) of all four models
  • The two red bars are the unbalanced models; the two tall bars were told to care about defaults
The lesson: on imbalanced data, telling the model to weight the rare class matters more than which model you pick.
